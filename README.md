# SanPlan: Documenting The Consumption of Medical Material
SanPlan is a full-stack progressive web app prototype to document the consumption of medical material during voluntary medical services at the Neu-Ulm Bavarian Red Cross.
The app was developed as part of my bachelor's thesis at Neu-Ulm University of Applied Science.

If you are curious, check out the [deployment at GitHub pages](https://marcoaigner.github.io/SanPlan/).
